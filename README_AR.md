# ElKingRouterControl PRO — Android

مشروع Android أولي لراوتر WE ZTE ZXHN H188A، بعنوان الإدارة المحلي `http://192.168.1.1/`.

## الموجود في النسخة 1.0
- واجهة عربية RTL بتصميم أسود وذهبي.
- شاشة رئيسية داخل التطبيق.
- فتح واجهة إدارة الراوتر الرسمية داخل WebView، دون الانتقال إلى Chrome.
- لا يخزن التطبيق اسم المستخدم أو كلمة المرور.

## البناء
1. فك ضغط الملف.
2. افتح مجلد `ElKingRouterControlPRO` في Android Studio أو AndroidIDE.
3. استخدم JDK 17.
4. انتظر Gradle Sync.
5. من قائمة Build اختر Build APK(s).
6. ملف APK التجريبي يظهر عادة في `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظات مهمة
- الهاتف يجب أن يكون متصلاً بشبكة الراوتر نفسه.
- عنوان الراوتر مضبوط على `192.168.1.1` وفق المعلومات التي أكدتها.
- هذه نسخة تأسيسية قابلة للبناء وليست بعدُ لوحة تحكم API كاملة.
- عرض الأجهزة الفعلية وتغيير Wi-Fi من شاشة التطبيق مباشرة يتطلب تحليل طلبات واجهة ZTE لهذا الـ firmware وتأكيدها على الجهاز؛ لم تتم إضافة أوامر تخمينية قد تغيّر إعدادات الراوتر.
- لا ترفع بيانات دخول الراوتر إلى أي خادم ولا تشاركها.
