# ElKingRouterControl – WebView Android

هذا مشروع Android بسيط يفتح واجهة إدارة الراوتر المحلية داخل التطبيق باستخدام WebView، بدلاً من iframe داخل موقع HTTPS.

## المتطلبات
- AndroidIDE على الهاتف (أو Android Studio على الكمبيوتر)
- JDK 17
- Android SDK Platform 35
- اتصال الهاتف بشبكة الراوتر نفسها

## البناء من الهاتف
1. فك ضغط الملف.
2. افتح AndroidIDE ثم Open Project واختر مجلد `ElKingRouterControl_WebView`.
3. وافق على مزامنة Gradle وانتظر تنزيل المكونات.
4. من قائمة Build اختر Assemble/Build APK.
5. ستجد الملف عادةً في:
   `app/build/outputs/apk/debug/app-debug.apk`

## التشغيل
- ثبّت APK على هاتفك.
- اتصل بشبكة Wi-Fi الخاصة بالراوتر.
- افتح التطبيق. سيحاول فتح `http://192.168.1.1/` داخله.

## ملاحظات مهمة
- هذا التطبيق يعرض صفحة الإدارة الرسمية فقط؛ لا يتجاوز تسجيل الدخول ولا يستخرج كلمة المرور.
- لا يحفظ بيانات الدخول.
- إذا لم تظهر الصفحة داخل التطبيق، جرّب التأكد من أن الهاتف متصل بشبكة الراوتر وأن `http://192.168.1.1` يعمل في Chrome.
- يسمح إعداد HTTP في هذا المشروع لتسهيل الوصول إلى واجهة الراوتر المحلية. لا تستخدمه لتصفح مواقع الإنترنت العامة.
- لا يحتوي المشروع على API غير موثقة لتغيير الإعدادات أو عرض الأجهزة؛ هذه الوظائف تحتاج توثيقًا رسميًا خاصًا بالراوتر.
