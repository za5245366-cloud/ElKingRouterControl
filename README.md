# ElKingRouterControl — Web Starter

واجهة عربية RTL بتصميم أسود وذهبي لمشروع إدارة الراوتر.

## تشغيل الموقع
1. فك ضغط الملف.
2. افتح `index.html` في المتصفح، أو افتح المجلد باستخدام VS Code ثم شغّل خادمًا محليًا.
3. يجب أن يكون الهاتف أو الكمبيوتر متصلًا بنفس شبكة الراوتر لفتح `http://192.168.0.1`.

## الملفات
- `index.html`: هيكل الصفحة.
- `style.css`: التصميم المتجاوب.
- `app.js`: تفاعلات بسيطة للواجهة.

## تنبيه مهم
هذه نسخة واجهة أمامية تجريبية فقط؛ لا تقرأ بيانات الراوتر ولا تغيّر إعداداته مباشرة. إدارة اسم الشبكة وكلمة المرور وإعادة التشغيل تتم من صفحة الراوتر الرسمية بعد تسجيل الدخول بصلاحية مخوّلة. ربط الواجهة بإدارة مباشرة يحتاج توثيقًا رسميًا لواجهات الراوتر وآلية مصادقة آمنة، ولا ينبغي تخزين كلمة مرور الإدارة داخل ملفات الموقع.
