# ElKingRouterControl PRO

نسخة واجهة ويب عربية احترافية بتصميم أسود وذهبي، مضبوطة على بوابة الراوتر `192.168.1.1`.

## الملفات
- `index.html` — الصفحة الرئيسية.
- `style.css` — التصميم المتجاوب.
- `app.js` — التنقل وتحديد رابط الراوتر.

## المعاينة
افتح `index.html` في المتصفح. لاختبار روابط الإدارة، افتح الموقع من جهاز متصل بنفس شبكة الراوتر ثم اضغط «فتح لوحة الراوتر».

## الرفع على GitHub Pages
1. فك ضغط الملف.
2. أنشئ مستودع GitHub جديداً.
3. ارفع الملفات الثلاثة (`index.html`, `style.css`, `app.js`) إلى جذر المستودع.
4. من Settings ثم Pages اختر Deploy from a branch، وحدد `main` و`/(root)` ثم Save.

## تنبيه مهم
هذه نسخة Front-end للواجهة والاختصارات فقط. ظهور صفحة تسجيل دخول الراوتر في متصفحك لا يعني أن موقعاً مستضافاً على الإنترنت يستطيع قراءة بياناته أو التحكم به تلقائياً. المتصفحات تمنع كثيراً من الاتصالات العابرة للنطاقات، كما أن الوصول المحلي يتطلب أن يكون جهازك على شبكة الراوتر. لم نضع بيانات الدخول في الموقع. لا توجد في هذه النسخة قراءة فعلية للأجهزة المتصلة أو تغيير لإعدادات Wi-Fi أو إعادة تشغيل الراوتر؛ يلزم لذلك تكامل موثق وآمن متوافق مع Firmware الجهاز.
