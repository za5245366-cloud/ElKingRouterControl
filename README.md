# ElKingRouterControl — Embedded Router Panel

واجهة عربية داخل الموقع تحاول عرض صفحة الإدارة المحلية `http://192.168.1.1/` باستخدام iframe.

## التشغيل والرفع
1. فك ضغط ZIP.
2. ارفع `index.html`, `style.css`, `app.js` إلى جذر موقعك.
3. افتح الموقع من جهاز متصل بنفس شبكة الراوتر.

## حدود iframe
قد يمنع الراوتر تضمين صفحة الدخول عبر `X-Frame-Options` أو `Content-Security-Policy`. لا يستطيع JavaScript في الموقع تجاوز هذه السياسات أو قراءة محتوى الإطار بسبب سياسة نفس الأصل. كما أن المتصفح لا يوفر إشارة موثوقة تميز منع التضمين عن تحميل بطيء؛ لذلك تحتوي الواجهة على رسالة احتياطية وإعادة محاولة.

## بديل آمن عند المنع
- لتجربة تبقى داخل تطبيق Android: استخدم Android WebView لفتح عنوان الراوتر مباشرة، وليس iframe داخل صفحة مستضافة.
- أو اربط الواجهة بواجهة API رسمية موثقة من الشركة عبر خدمة محلية على الشبكة، مع جلسة مصادقة آمنة وصلاحيات محدودة.
- لا تنشئ proxy يعيد تمرير صفحة تسجيل دخول الراوتر أو يخزن كلمة مرور المسؤول أو ملفات تعريف الارتباط. هذا قد يكشف جلسة الإدارة. ولا تحاول إزالة/تجاوز ترويسات الحماية.

## تنبيه HTTP/HTTPS
إذا كان موقعك منشوراً على HTTPS، فقد يمنع المتصفح تحميل `http://192.168.1.1` داخل iframe باعتباره محتوى مختلطاً (Mixed Content). صفحة GitHub Pages لا تستطيع إصلاح ذلك من جهة العميل. استخدم تطبيق Android محلياً أو تكاملاً رسمياً آمناً بدلاً من وسيط غير موثوق.
